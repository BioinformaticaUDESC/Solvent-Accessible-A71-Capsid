# Data inventory

This package contains existing files selected for review. It does not establish
which structures were retained or excluded in the scientific analysis.
No fixed count of 39 retained structures, six exclusions, calibration split,
random seed, or exclusion rationale is inferred from filenames or file hashes.
Those claims must be verified against the actual analysis records before release.

Deduplication is restricted to the same logical filename (download suffixes
_02 and _03). Copies are collapsed only when their SHA-256 hashes agree.
Identical contents under distinct structure identifiers are retained separately.
The requested preference for a _V49 version is applied within each filename group.
Conflicting variants are not silently resolved by modification time.

The original tables are not recomputed or edited. Consult the actual headers
for their columns. Coordinates and exploratory docking outputs are excluded.
